# TanStack Query

一个异步状态管理库，用来简化服务端状态的获取、缓存、同步与更新。

- 与协议无关的数据获取（REST、GraphQL、Promise 等）
- 缓存、重新获取、分页与无限滚动
- 变更（mutation）、依赖查询与后台更新
- 预取、取消请求，以及 React Suspense 支持
